## Render on the PC (i7-7700K + GTX 1050, Windows)
```bash
git pull
npm install
scripts/render_promo.sh          # Git Bash; uses --gl=angle and 6 threads
# no GPU / errors with angle:  GL=swangle CONC=4 scripts/render_promo.sh
```
Output: `out/promo_unidos_upload.mp4` (-14 LUFS, metadata stripped).
Without Git Bash, run these two lines and post the `_raw.mp4` directly:
```bash
npx remotion bundle src/index.ts --out-dir=build_promo
npx remotion render build_promo PromoUnidos out/promo_unidos_raw.mp4 --gl=angle --concurrency=6 --crf=18
```
Preview and edit live with `npx remotion studio`, then pick **PromoUnidos**.
To review before sending, check a sheet every 0.5 s (CLAUDE.md rule), especially the accents (Ó, É, Ã), which
were clipped once and then fixed.
